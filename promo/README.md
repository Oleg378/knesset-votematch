## Обложка для Instagram — как выгружать

Если обложку для публикации (или её страницу 2 — кадр «Обложка для публикации страница 2» там же, 577:1319) надо выгрузить для Instagram заново (например, после правки в Figma), делать в этом качестве:

1. Источник — кадр «Обложка для публикации» на странице Page 1 в Figma (567:1303), а не скриншот.
2. Размер — ровно **1080×1350** (4:5, максимум ленты Instagram для вертикального поста). Крупнее не нужно: Instagram сам
   уменьшит и пережмёт, обычно мыльнее.
3. Лучшее качество: выгрузить кадр PNG **×4** (4320×5400) и уменьшить до 1080×1350 усреднением 4×4 — каждый пиксель из 16
   точек, края букв ровнее; сохранить PNG с пометкой sRGB. Так сделан `cover-instagram.png`.
4. Быстрый вариант: PNG **1x** прямо из Figma (настройка экспорта у кадра уже стоит) — разница с п. 3 на глаз почти не видна.
5. В приложении Instagram включить «Загружать в самом высоком качестве» (Использование данных и качество медиа).
6. Анимированную обложку Instagram принимает только видео: брать mp4 1080×1350 той же гифки, GIF в ленту не загружается.

История вариантов и решений — `web/DECISIONS.md`, абзац о промо.
