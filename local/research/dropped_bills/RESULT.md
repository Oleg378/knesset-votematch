# Законопроекты, выпавшие из квиза полностью (2026-10-20)

Набор (решение заказчика 2026-10-20): все снятия `overrides.json` «remove», после которых у законопроекта не осталось метки ни на одном направлении с вопросом — 611 законопроектов, 399 названий без года. Вход — `scripts/dropped_input.py` (название, 160 символов записки, причина снятия; каталог 358 текущих направлений без пометки, у каких есть вопрос). Две слепые группировки (Opus, правило темы из пилота PASS2 + сверка с каталогом: совпадение → id, иначе новая тема с «+»/«−»): `A/`, `B/`; сверка — `scripts/dropped_compare.py` → `compare.md`, `compare.csv`.

- A: 185 тем (100 совпали с каталогом), 15 технических; B: 211 (107), 18. Согласие по парам «вместе» F1 0,85; одинаковый ответ по каталогу — 341 из 399.
- Оба агента: одно и то же направление каталога — 187 названий; оба — новая тема — 136; оба — технический — 15; расходятся — 61.
- Размер тем: 1 название — 100 (A) / 135 (B); 2–4 — 70 / 64; ≥ 5 (только такие могут пройти порог объёма) — 15 / 12.
