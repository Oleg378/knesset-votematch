# H9 — проверка разметки человеком

50 частных законопроектов, у каждого есть пояснительная записка. Отобраны случайно (seed 20261014) из 8 408 законопроектов, которые внесли кандидаты 2026 года, бывшие депутатами 24–25 созывов. Именно на авторстве этих законопроектов строится слой тем (SU п. 27.2). Законопроекты, которые уже проверял эксперт, исключены.

Файл: `h9_sample.csv` (открывается в Google Sheets / Excel). В каждой строке:
- ссылка на страницу законопроекта на сайте Кнессета;
- название;
- первые 500 символов пояснительной записки;
- темы по разметке со знаком: «+» — закон увеличивает величину, «−» — уменьшает, «?» — знак не определён.

Что заполнить:
- **главная_верна** — да / нет / частично: правильно ли выбрана главная тема;
- **знаки_верны** — да / нет: правильные ли знаки у всех тем;
- **лишние_темы** — темы, которые закон на самом деле не двигает;
- **пропущенные_темы** — своими словами, чего не хватает;
- **комментарий** — по желанию.

Определения направлений («+» и «−») — в `jef/directions/DIRECTIONS_LIST.md`. На один законопроект — 2–3 минуты, на всю выборку — около 2 часов.
