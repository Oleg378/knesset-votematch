# Протокол проверки квиза на людях (черновик, 2026-10-22)

_Заготовка по внешнему аудиту №3 (п. 2.2, 3, 6.5): до запуска проверки протокол фиксируется, после — не меняется. Статус [А]._

## 1. Что проверяем
1. **Точность сопоставления**: получает ли избиратель с известным намерением голосовать свой список первым / в первой тройке.
2. **Правильность позиций списков**: совпадает ли сторона списка по вопросу (toward / against / no clear position) с оценкой людей, знающих Кнессет.
3. **Устойчивость**: тот же человек через неделю — тот же результат?

## 2. Когда
- До 27.10.2026: только п. 2 на малом объёме (ядро 12 × 8 = 96 клеток и 24 отложенные пары `HUMAN_GOLD_FORM.md`), если найдутся 2–3 человека.
- После выборов: п. 1 и 3 на панели.

## 3. Панель (п. 1, 3)
- Набор: добровольцы через страницу квиза после результатов («помочь проверке»: намерение голосовать + согласие), цель — не меньше 100 человек на каждый из 12 оцениваемых списков, иначе список не оценивается отдельно.
- Прохождение штатное: 8 + 7 + размены, без подсказок. Сохраняются только ответы и намерение, без идентификаторов (решение о хранении ответов — отдельное, сейчас ответы не хранятся).
- Метрики, зафиксированные заранее: доля «свой список 1-й», «в первой тройке», «верный кластер»; то же по каждому списку; сравнение с базовым правилом «самооценка лево — право + религиозность» (два вопроса в анкете).
- Повтор через 7–14 дней у согласившихся: доля совпадений первого места.

## 4. Проверка позиций (п. 2)
- Два–три эксперта независимо, вслепую (без наших значений), по бланку: список × вопрос → «за / против / нет явной позиции / не знаю».
- Согласие эксперт — квиз считается там, где квиз называет сторону; расхождения двух экспертов с квизом → клетка помечается на странице методологии и разбирается по законопроектам.
- Пороги не пересматриваются по итогам этой проверки (иначе она перестаёт быть проверкой).

## 5. Что публикуется
Все числа п. 3–4, включая плохие, на странице методологии; протокол — в репозитории до начала сбора.
