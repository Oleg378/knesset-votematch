# Систематическая проверка разметки по вопросам квиза

_Порядок, по которому 2026-10-19 проверена тема «Imports and competition» (q42) и по которому проверяются остальные вопросы — по одному за раз. Прогресс — [LABEL_CHECK_PROGRESS.md](LABEL_CHECK_PROGRESS.md). Метки: [У] — утверждено заказчиком, [А] — предложение исполнителя._

## Что проверяем

Все законопроекты, которые разметка относит к теме вопроса (`export/quiz_bills.v2.json` → `by_direction[d]`), — не выборку. Вопрос: соответствует ли законопроект **вопросу** (тексту утверждения) по существу, а не только широкой теме, и в какую сторону.

## Шаги

1. **Материал** (`local/research/scripts/core_full_input.py`, `QS=<q> TAG=<имя> PARTS=<n>`): законопроекты темы, сгруппированные по названию без года (повторное внесение — один пункт); у каждого — текст утверждения, тема с «+» и «−», название, начало пояснительной записки. Нашей метки и знака проверяющий не видит. Части по ~80 пунктов.
2. **Первая проверка вслепую** (агент Opus на часть): `about` / `not_about` / `borderline` и знак.
3. **Если прямо про вопрос меньше половины пунктов** [А, порог на утверждение] — это несовпадение вопроса с темой, а не ошибки отдельных меток: **стандартный аудит** утверждения (`statement_audit.py`, тот же промпт: оставить / переписать шире / разделить). При «разделить» — Jev выбирает часть для каждого законопроекта (`plan4.json`, `jev_split.py --stage4`), части проходят обычный отбор, вопрос переходит на подходящую часть, новые тексты — заказчику.
4. **Вторая проверка вслепую** предложенных снятий (пункты `not_about`, оставшиеся на теме после шага 3) вперемешку с контрольными (`about`) — не меньше трети от числа кандидатов.
5. **Решение** [У]: метка снимается, если две проверки сказали «не про вопрос»; если вторая сказала «спорно» — третья проверка, решение большинством из трёх (`overrides.json` «remove», `borderline_resolved.csv`). Расхождение знака — так же двумя проверками («flip»).
6. **Пересчёт:** коммит входных данных → `make data` → отбор (все вопросы проходят?) → ядро → тесты → коммит экспорта. Запись в прогресс.

## Пример: q42 «Imports and competition» (2026-10-19)

159 названий; прямо про вопрос 27 % → стандартный аудит → разделение темы 25: 25a «открытие рынков для конкуренции» (q42), 25b «предпочтение местных поставщиков в госзакупках» (новый q107). Вторая проверка: 11 из 23 «не про вопрос» подтверждены (27 меток), контрольные 12/12; третья проверка спорных — ещё 3 (8 меток). Стоимость: ≈ 6 запусков агентов, Jev $0,025.
