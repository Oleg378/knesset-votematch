# export/ — the data contract for the web

Generated by `make data` (`pipeline/positions.py`, then `pipeline/export.py`); never edited by hand. The web reads these files and nothing else.

| File | Read it when |
|---|---|
| `WEB_CONTRACT.md` | **first** — files, loading, the order of questions, list details, golden cases, composition |
| `METHODOLOGY_PAGE.md` | texts of the Methodology and Positions pages, English as shown |
| `quiz_core.json`, `quiz_data.json`, `quiz_bills.json` | the data: the core is bundled with the app, the other two are fetched in this order |
| `quiz_data.schema.json`, `golden.json` | tests: schema of the merged data; Python results the TypeScript port must reproduce |

Reference implementation: `pipeline/quiz_match.py` (closeness, trade-offs), `pipeline/quiz_flow.py` (order of questions), `pipeline/quiz_report.py` (explanations); the whole flow in the terminal — `python3 pipeline/quiz_cli.py --no-save`. How it all works — `docs/TECHNICAL.md`.
